# Daylight To-do List

A calm, responsive task list with completion filters, remove/clear actions, and automatic browser storage.

## Features

- Add, complete, filter, and remove tasks
- Clear all completed tasks at once
- Automatically save tasks in the current browser
- Responsive layout with no external dependencies

## Run locally

Open `index.html` in a browser. No build step or external dependencies are required.

## Deployment

GitHub Pages deploys automatically from `main` through the included Actions workflow.
